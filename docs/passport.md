## 1. Название проекта
ДенисоАмироВорк

## 2. Проблема
Продавец записывает товар в тетрадку, покупатель не видит, что есть в наличии, заказы теряются

## 3. Пользователи
Клиент, продавец, администратор

## 4. Цель проекта
Дать покупателю возможность заказать обувь онлайн, а продавцу — видеть актуальные остатки


## 5. Метрики успеха
 - Покупатель находит нужную обувь за 3 клика.
 - Оформление заказа - меньше 2 минут.
 - Продавец добавляет новый товар — меньше 1 минуты.

## 6. Границы (что НЕ делаем)
 - Не делаем онлайн-оплату — только имитация.
 - Не делаем мобильную версию — только Windows.
 - Не делаем доставку — выдача в магазине.

## 7. Риски
 - Не успеем сделать всё → сначала каталог и корзина, остальное потом.
 - Мало товаров для каталога → возьмём реальные модели из открытых источников.
 - Мало людей в команде → чётко разделим, кто что делает.
